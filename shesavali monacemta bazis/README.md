# 🚗 ავტომობილების ბაზა (Cars Database)

## 📋 პროექტის აღწერა

ეს პროექტი შეიცავს SQLite მონაცემთა ბაზას ავტომობილების ინფორმაციით. ბაზაში მოთავსებული არის `cars` ცხრილი 12 ავტომობილის ჩანაწერით.

## 📁 ფაილები

- **`cars.db`** - SQLite მონაცემთა ბაზა
- **`setup_database.py`** - ბაზის შექმნის Python სკრიპტი
- **`query_database.py`** - ბაზის გამოკითხვის Python სკრიპტი
- **`cars_database.sql`** - SQL სკრიპტი (იმ შემთხვევაში, თუ სხვა ბაზის სისტემა გამოიყენება)

## 🗂️ ბაზის სტრუქტურა

### `cars` ცხრილი

| სვეტი           | ტიპი          | აღწერა                                                  |
| --------------- | ------------- | ------------------------------------------------------- |
| `car_id`        | INTEGER       | ავტომატურად ზრდადი პირველადი გასაღები                   |
| `brand`         | VARCHAR(100)  | ბრენდი (NOT NULL)                                       |
| `model`         | VARCHAR(100)  | მოდელი (NOT NULL)                                       |
| `year`          | INTEGER       | გამოშვების წელი (NOT NULL)                              |
| `vin_code`      | VARCHAR(17)   | ვინ კოდი (უნიკალური, მაქსიმუმ 17 სიმბოლო)               |
| `added_date`    | TIMESTAMP     | დამატების თარიღი (ავტომატურად შეივსება შექმნის თარიღით) |
| `engine_volume` | DECIMAL(5,2)  | ძრავის მოცულობა (CHECK: > 0.5)                          |
| `mileage_km`    | INTEGER       | გარბენი კილომეტრებში                                    |
| `is_cleared`    | BOOLEAN       | განბაჟებულია თუ არა                                     |
| `price`         | DECIMAL(10,2) | ფასი (მაქსიმუმ 10 ციფრი, 2 სიმბოლო ათობითი ნაწილი)      |
| `description`   | TEXT          | აღწერა (შეზღუდვის გარეშე)                               |
| `is_sold`       | BOOLEAN       | გაყიდული თუ არა                                         |

## 🚀 გამოყენება

### ბაზის პირველადი შექმნა

```bash
python setup_database.py
```

ეს ბრძანება:

- შექმნის `cars.db` ფაილს (თუ არ არსებობს)
- შექმნის `cars` ცხრილს
- დაემატება 12 ავტომობილის ჩანაწერი

### ბაზის გამოკითხვა

```bash
python query_database.py
```

ეს ბრძანება ჩვენებს:

- ყველა ავტომობილის სრული ლისტი
- საერთო სტატისტიკა
